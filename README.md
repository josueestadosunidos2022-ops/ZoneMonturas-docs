# ZoneMonturas 0.1.0-beta17

## English

Owned custom mounts, a stable, mount abilities, administrator grants and player mount trading. Open the stable with /montura; /montura invocar and /montura guardar summon/store the selected owned mount. /zonemonturas reload reloads config/ZONEMODS/zonemonturas/monturas.toml. Purchases/trades use the optional ZoneCrates wallet integration. Publish the matched beta17 pair; do not mix it with beta16 or earlier. Preserve owned mounts and existing data.

## Español

Monturas propias, establo, habilidades, concesiones administrativas e intercambios. Abre el establo con /montura; /montura invocar y guardar gestionan la montura seleccionada que posees. /zonemonturas reload recarga config/ZONEMODS/zonemonturas/monturas.toml. Compras/intercambios usan la integración opcional de cartera ZoneCrates. Usa el par beta17 sin mezclar beta16 o anteriores y conserva propiedad/datos existentes.

| client | 0.1.0-beta17 | `zonemonturas-client-0.1.0-beta17-protected.jar` |

## Dependencies / Dependencias

- **server**: zonecrates: Optional Dependency (wallet integration)
- **client**: zonecrates: Optional Dependency (wallet integration)

## Installation / Instalación

Install only the file for each side. Never mix two versions or both side distributions in one mods folder. Back up the world and preserve TOML/player data. Dedicated-server-only mods do not belong in a client modpack.

Instala solo el archivo del lado correspondiente. No mezcles versiones ni ambos JAR en una carpeta mods. Respalda mundo y conserva TOML/progreso. Los mods exclusivos de servidor no van en el modpack de cliente.

Protected public files retain features without distributing private source, mappings or production configuration/account data. File/resources/shared schemas and isolated server startup/clean save were checked; no new GUI/full-modpack or live multiplayer test was performed. File availability depends on CurseForge approval.

Los archivos públicos conservan funciones con protección, sin fuentes, mappings ni datos privados. Se verificaron archivos/esquemas y arranque/cierre local aislado; no una nueva prueba gráfica o multijugador real. Disponibilidad sujeta a aprobación de CurseForge.
